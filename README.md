# E-Commerce-Analysis
Power BI analysis of the Olist Brazilian e-commerce dataset with interactive sales, customer, seller, and product insights.

1. Project Title:
Olist E-Commerce Sales Analytics Dashboard

2. Short Description / Purpose:
Olist E-Commerce Sales Analytics Dashboard is a Power BI project designed to analyze e-commerce sales, customer behavior, product performance, and delivery trends. It provides interactive visualizations and key business insights to support data-driven decision-making.

3. Tech Stack:
Power BI – Data cleaning, data transformation, data modeling, interactive visualizations, KPI cards, slicers, and dashboard development.
Power Query – Data importing, filtering, cleaning, handling missing values, removing duplicates, and transforming the dataset.
DAX – Created measures and calculated metrics such as Total Sales, Total Orders, Total Customers, and Average Review Score.
CSV / Excel – Used as the source dataset.

4. Data Source:
Olist Brazilian E-Commerce Public Dataset – The dataset contains information about orders, customers, sellers, products, payments, reviews, and order delivery details. The data was imported into Power BI for cleaning, transformation, analysis, and dashboard creation.

5. Features / Highlights:
Overall sales & order performance tracking
KPI-based business performance monitoring
Monthly sales trends analysis
Product/category performance analysis
Location/state-wise performance analysis
Customer review analysis
Delivery performance tracking
Interactive slicers and filters for deeper analysis
